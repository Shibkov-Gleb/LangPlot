# LangPlot

Локальный сервис изучения языков через интерактивные истории. В [English A2](http://localhost:3000/courses/en/a2) доступны все 90 уроков «Последней переклички», оба пути 31–45 и три развязки. Прогресс, решения и переписки сохраняются. После урока можно открыть теорию, продолжить сюжет или начать отдельную попытку. После финала доступна короткая сверка ошибок из журнала. Телефон использует фиксированные локальные ответы.

## Быстрый запуск

Нужны **Node.js 22**, **pnpm 10.28.2**, Docker Desktop с запущенным Linux-движком. Проверяйте `node --version` и `pnpm --version`: некоторые оболочки подставляют собственный Node. Версии библиотек и lockfile закреплены.

В PowerShell из корня репозитория:

```powershell
# Если pnpm ещё не установлен:
npm install --global pnpm@10.28.2

# Только при первой настройке, чтобы не перезаписать свои параметры:
Copy-Item .env.example .env
pnpm install --frozen-lockfile
pnpm db:generate
pnpm db:up
pnpm db:migrate
pnpm dev
```

Откройте **http://localhost:3000** → «Выбрать язык» → «Создать аккаунт» или «Войти».

- Next.js: `localhost:3000`, слушает loopback.
- Express: `127.0.0.1:4000`; браузер обращается к нему через Next `/api`.
- PostgreSQL: `127.0.0.1:55432`, постоянный Docker volume `langplot-data`.
- `GET /api/health` проверяет и сервер, и подключение к базе.
- `pnpm db:down` останавливает контейнер, **сохраняя данные**.

Интернет нужен для первоначальной установки пакетов и Docker-образа. Пользовательские сценарии приложения работают локально. Картинки и шрифты включены в проект/зависимости и обслуживаются тем же сервером.

На текущем компьютере системная обёртка `pnpm` выбирает другой Node. Для воспроизводимого запуска в каждом новом терминале PowerShell используйте установленный локально pnpm:

```powershell
# Уже установлено в этой рабочей папке; для новой копии репозитория:
npm install --prefix .local/tools pnpm@10.28.2 --ignore-scripts --no-audit --no-fund
$env:PATH = "C:\Program Files\nodejs;$PWD\.local\tools\node_modules\.bin;$env:PATH"
node --version # 22.x
pnpm --version # 10.28.2
```

## Если Docker не запускается на этом Windows-компьютере

При реализации Docker Desktop завершался с таймаутом DNS `host.docker.internal`. Повреждённый старый сокет его Inference-модуля был устранён, настройки Docker возвращены к исходным. Сетевые настройки системы не менялись. Compose подготовлен, но запуск контейнера в этой среде не подтверждён.

Для рабочего просмотра и тестов использован отдельный PostgreSQL **17.7** в `.local`, с тем же протоколом, портом и миграциями. Резервный путь не меняет архитектуру приложения. Суффикс beta относится к npm-обёртке бинарного дистрибутива.

```powershell
npm install --prefix .local/postgres @embedded-postgres/windows-x64@17.7.0-beta.16 --ignore-scripts --no-audit --no-fund
pnpm db:generate
pnpm db:local
```

Оставьте этот терминал открытым. Во втором:

```powershell
pnpm db:migrate
pnpm dev
```

`db:local` создаёт `.local/pgdata-local` и базу `langplot` при первом запуске. Повторный запуск сохраняет данные. Завершение — Ctrl+C. Не запускайте одновременно Docker-базу и резервную базу на одном порту. Это **разные хранилища данных**: автоматического переноса между ними нет.

Порт 55432 выбран потому, что 54329 на этой машине входит в диапазон, зарезервированный Windows/Hyper-V. Не меняйте системные резервирования ради приложения.

## Что проверить в интерфейсе

1. На главной — языковые миры, анимации появления, FAQ и переход в кабинет.
2. В «Моих мирах» выберите язык и нажмите на уровень. [English A2](http://localhost:3000/courses/en/a2) открывает список уроков «Последней переклички». У завершённого урока доступны повторное прохождение и теория. Вся открытая теория также хранится в [материалах](http://localhost:3000/dashboard/materials).
3. В «Настройках» — имя, родной язык, звук, субтитры и уменьшение анимации. Озвучки пока нет; переключатель сохраняет предпочтение.
4. В «Настройках» можно бесплатно активировать тестовую подписку. Ученики с обоими статусами проходят один и тот же курс.
5. В карточках других уровней и немецкого направления отображается «В разработке». Игровой экран открывается из урока A2.

## Доступ к администрированию

На компьютере с базой выполните `pnpm admin:invite` после миграции. Откройте адрес из `.local/admin-invite.txt` в браузере и создайте аккаунт главного администратора. Ссылка действует 24 часа, используется один раз. Повторная команда заменяет старую ссылку, пока главный администратор ещё не создан. Файл приглашения исключён из Git.

В [администрировании](http://localhost:3000/admin) доступны поиск по имени и почте, фильтры ролей и статусов, список контактов на сегодня и просроченных контактов. Откройте карточку ученика, чтобы посмотреть последние занятия, оставить внутреннюю заметку или назначить дату контакта. Изменения записываются в историю с автором и датой.

| Доступ                | Возможности                                                                                                                        |
| --------------------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| Без подписки          | Курс A2, сохранения, материалы, профиль и тестовое подключение подписки                                                            |
| С подпиской           | Те же учебные возможности                                                                                                          |
| Администратор         | Учебный кабинет, CRM, студия, создание и импорт черновиков                                                                         |
| Главный администратор | Все возможности администратора, задания студии всех администраторов, назначение и снятие административных прав в карточке аккаунта |

После снятия прав восстанавливается статус подписки ученика. Права API проверяет по базе при каждом запросе. Общий демо-профиль и его прежние прохождения сохраняются в базе отдельно от личных аккаунтов. Миграция завершает прежние демо-сессии.

## Команды и проверки

```powershell
pnpm typecheck
pnpm test
pnpm test:api
pnpm build
pnpm format:check

# Локальный просмотр собранного frontend (при запущенной базе):
pnpm preview

# Браузерные тесты: сначала запустите pnpm dev или pnpm preview
pnpm exec playwright install chromium --no-shell
pnpm test:e2e
```

API-тесты применяют миграции к отдельной временной схеме `langplot_test_<uuid>` в PostgreSQL, затем удаляют только эту схему. Демо-данные приложения они не затрагивают. Для отдельной тестовой базы можно задать `TEST_DATABASE_URL`. Браузерные проверки создают временные аккаунты и удаляют их после сценария.

Браузерные проекты: 375, 768 и 1440 px; проверяются отсутствие горизонтального переполнения, сохранение выбора/настроек, телефон, экспорт/импорт, клавиатура и `prefers-reduced-motion`. Скриншоты находятся в `test-results/`, HTML-отчёт — в `playwright-report/`.

На текущем Windows скачанный Chromium не стартовал из-за ошибки side-by-side configuration. Проверки выполняются в установленном Edge:

```powershell
$env:PLAYWRIGHT_CHANNEL = 'msedge'
pnpm test:e2e
```

Установленный антивирус внедряет собственные запросы к `me.kis.v2.scr.kaspersky-labs.com`. Тест сетевой автономности исключает только этот известный внедрённый адрес, не отключая антивирус. Другие внешние запросы считаются ошибкой.

## Конфигурация и следующий этап

`.env.example` содержит все параметры. `dev` и `preview` передают их обоим приложениям. `PORT` задаёт порт Express; frontend явно запускается на 3000 в `apps/web/package.json`. При изменении портов согласованно обновляйте команды frontend, `PORT`, `API_ORIGIN` и `WEB_ORIGIN`; после изменения `API_ORIGIN` пересоберите frontend. Секреты в браузер не передаются. `.env`, `.local`, сохранения и результаты тестов исключены из Git.

`CHAT_PROVIDER=local` и `COURSE_PROVIDER=local` включают тестовые реализации; значение `none` возвращает понятный статус «Не настроено». TTS пока поддерживает только `none`. Внешняя трассировка LangSmith отключается на сервере независимо от унаследованного окружения.

Основа рассчитана на **один локальный процесс Express**. Следующие этапы: проверенные медиаресурсы, педагогическая модель персонализации, очередь фоновых задач и российское размещение базы/файлов. Публикация курсов намеренно ещё не подключена. Интерфейсы LLM, TTS и файлового хранилища подготовлены для заменяемых реализаций.
