# Работа над пакетами LangPlot

Перед изменениями прочитайте `../docs/CONTENT_AUTHORING.md` и схему `../packages/shared/src/content.ts`.

- На текущем этапе создавайте только пустые черновые каркасы. Сюжеты и учебные главы добавляйте после отдельного задания пользователя.
- Для локальной работы и API используйте один формат JSON с `schemaVersion: 1`.
- Существующие импортированные версии неизменяемы: новые данные требуют нового `manifest.version`.
- Условия переходов декларативные. Не добавляйте исполняемый код, сетевые URL, абсолютные пути или секреты.
- Из корня репозитория проверяйте пакет командой `pnpm content validate ../../content/<путь>.json`. CLI работает из `apps/api`; абсолютный путь также допустим.
- Пустой каркас должен проходить обычную проверку и не проходить `--publish`.
- Новые механики требуют изменения общего движка/версии схемы и соответствующих тестов. Обычные главы не должны требовать изменения кода интерфейса.
