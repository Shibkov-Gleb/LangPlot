# Проверка основы LangPlot

## Серверный запуск — 12 ноября 2026 года

Проверен настоящий Linux-стек в Docker Desktop: PostgreSQL 17, миграции, собранный Express, Next.js standalone и Caddy. Изолированный проект `langplot-server-check` использовал отдельные тома и порты; локальная пользовательская база и ключи не использовались. Сборка устанавливает зависимости по lockfile, генерирует Prisma Client под Linux и запускает API обычным Node без `tsx`.

- Типизация всех пакетов, production-сборки API и Next.js прошли.
- 102 модульных теста и 28 API-проверок с настоящим PostgreSQL прошли. Добавлены проверки production-окружения: HTTPS, параметры сети, ключ провайдера, безопасные сообщения об ошибках и запрет публичного QA-исключения из аналитики.
- Через HTTPS проверены здоровье базы/API, регистрация, сохранение настроек/уровня, Secure/HttpOnly/SameSite cookie, запрет стороннего Origin, демо-входа и доступа ученика к студии. Работают оптимизация изображений и частичная загрузка MP3.
- Приглашение владельца создано внутри контейнера и использовано однократно. Проверены CRM, CSV с BOM, назначение администратора и отказ обычному администратору в выгрузке контактов.
- Существующие браузерные сценарии прошли 12/12 на 375, 768 и 1440 px: гостевой урок до регистрации, перенос прогресса, кабинет, CRM/CSV, озвучка, клавиатура и уменьшенное движение. На этом компьютере Kaspersky блокирует самоподписанный сертификат localhost в Edge; UI проверен через временный loopback HTTP-мост к тому же HTTPS-стеку. Проверки самого HTTPS выполнены отдельно через HTTP-клиент Playwright. Защита антивируса и production-конфигурация для этого не менялись.
- Создан бинарный дамп новым скриптом и восстановлен в отдельную базу. Проверены профиль и выбранный уровень, отказ перезаписывать существующую базу и удаление временного файла при ошибке копирования.
- После перезапуска API во время переписки и пересоздания контейнера PostgreSQL сохранились сессия, профиль, редакция/сцена прохождения и единственный ответ персонажа. Проверены непривилегированный пользователь процесса, запрет записи в образ, права `600` на приглашение и отсутствие файлов `.env` в контейнере.

В этом прогоне переписка использовала `CHAT_PROVIDER=local`, без платных запросов к DeepSeek. Готовые Gemini MP3 воспроизводились из образа сайта. Выпуск публичного сертификата требует настоящего домена и проверяется при развёртывании на сервере. Инструкция: [DEPLOYMENT.md](DEPLOYMENT.md).

## Личные аккаунты, CRM и English A2 — 10 ноября 2026 года

Типизация всех пакетов и production-сборка прошли. Успешны 89 модульных тестов и 18 проверок API с PostgreSQL. Проверены регистрация и вход, одноразовое приглашение владельца, ограничения всех четырёх ролей, активация подписки, выдача и отзыв административных прав в действующей сессии, внутренние заметки и фильтры CRM.

В Edge проверены девять сценариев на ширинах 375, 768 и 1440 px: кабинет ученика и администратора, управление с клавиатуры и обе ветки первого урока с перепиской, сохранением и теорией. Четыре сценария повторно прошли на собранном приложении после обновления проверки грамматической статьи и завершения перезапусков сервера разработки. Снимки каталога и CRM сохранены в `.local/qa`.

API-проверки охватывают сессии, запрет демо-режима в production, владение прохождениями, конкурентные действия и повтор ID, восстановление данных, сбой и повтор переписки, отмену, импорт/экспорт, неизменяемость версий, ограничение размера/путей, прерванные задания и запрет публикации пустого черновика.

Браузер проверяет главную, вход, выбор немецкого/B1, настройки, обновление страницы, техническую сцену, телефон с повтором ошибки, студию, экспорт и обратный импорт, выход. Ширины — 375, 768 и 1440 px. Скриншоты главной, кабинета, игры, телефона и студии сохранены в `test-results`; выбранные снимки для просмотра — `.local/qa`. Горизонтального переполнения и ошибок JavaScript в проверенных сценариях нет. Приложение не обращается к внешним сервисам; исключение в сетевой проверке относится только к внедрённому скрипту установленного антивируса.

Визуально проверены первый экран на трёх ширинах, кабинет, телефон и мобильная студия. У элементов навигации есть доступные названия; скрытая ссылка перехода к содержимому появляется при фокусе. Это целевая проверка основных сценариев, а не полный аудит WCAG.

## Ограничения первоначальной проверки 4 ноября

- Docker Compose подготовлен, но контейнер не запущен: Docker Desktop останавливается на таймауте DNS `host.docker.internal`. Фактические проверки выполнены на отдельном локальном PostgreSQL, запущенном через `pnpm db:local`.
- Загруженный Chromium не стартует из-за Windows side-by-side configuration; используется установленный Edge через `PLAYWRIGHT_CHANNEL=msedge`.
- Интеграции TTS и внешних LLM не проверяются: их подключение не входит в текущий этап. Тестовые ответы и черновики создаются локально.
- Реальные курсы, педагогическая оценка, регистрация, публикация контента и платежи ещё не реализованы. Демо-режим рассчитан на один локальный процесс API и один общий тестовый профиль.
